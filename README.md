# 🎵 Quefy — Smart Social Jukebox

**Quefy** — це інтерактивний додаток для спільне керування музикою на вечірках, в офісах чи під час відпочинку з друзями. Більше жодних суперечок біля колонки: скануй QR-код, додавай треки та голосуй за плейлист у реальному часі.

---

## 📲 Як це працює

1. **Створення кімнати:** Хост відкриває Quefy і підключає колонку.
2. **Спільний плейлист:** Кожен додає свої улюблені треки у загальну чергу.
3. **Демократія в дії:** Учасники лайкають пісні — треки з найбільшою кількістю голосів піднімаються нагору.

---

## ✨ Ключові фічі

- **AI Fair-Play (Анти-спам):** Розумний алгоритм балансує чергу, щоб одна людина не заповнила її лише своїми треками.
- **Fair Skip:** Колективний пропуск треку, якщо більшість учасників проголосувала «проти».
- **Vibe Match:** Хост може встановити фільтр настрою (наприклад, *«Тільки драйвова музика»*), і система попереджатиме про треки, що випадають з атмосфери.
